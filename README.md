# Pulse — Daily Tasks & Expense Dashboard

A fast, zero-backend personal daily checklist, expense tracker, and analytics dashboard hosted on **GitHub Pages** (no local server required).

## Features

- **Daily Checklist & Recurring Habits:** Add tasks, mark complete/incomplete, set priorities, and auto-repeat daily routines.
- **Daily Expense Tracker:** Log expenses by category & payment method, search/filter the ledger, and monitor your monthly budget.
- **Weekly & Monthly Analytics Dashboard:** Interactive SVG bar charts for task completion and daily spending, category donut chart, streaks, and a 30-day consistency heatmap.
- **Zero Server Needed:** Runs 100% in your browser via GitHub Pages. All data is saved automatically in your browser's `localStorage` with one-click **JSON Backup / Restore** and **CSV Export**.
